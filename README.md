# Noria

**Discover liquidity. Coordinate capital.**

Noria is being prepared for **ETHOnline 2026**, targeting **The Graph — Best AI Tooling or AI Use Case with The Graph** track.

The current product discovers Uniswap v3 pools, proposes ranges and explains inventory, source quality and capacity through a web interface and reusable MCP tools. The Graph supplies live indexed data; canonical RPC reads and independent price references support verification.

A future module is planned for the **1inch track**, using **1inch Aqua** for liquidity execution and **Aave** for collateralized borrowing. That execution module is **not implemented in this release**.

The application, tests and full documentation are being introduced through small, reviewed pull requests. No wallet actions are available in the current product.
